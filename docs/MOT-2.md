# MOT-2 · 学习态变化

相对 `main@57d50b8`（UX-3 已合入）。本刀在 MOT-1 的 token 上，把听写 / 核对 / 听读里的状态变化交代清楚。不发明新的时长或曲线，也不回头改 UX-3 的软口，不动 v0.1.3 Release。

## Token

继续用 `src/app/styles.css` 的 `:root` 与 `src/app/motion.ts` 的 `MOTION_MS`：

- **微** `--motion-micro: 100ms`：切句内容更换、播放 / 暂停图标切换、按下
- **短** `--motion-short: 180ms`：核对结果出现与收回、显示 / 收起画面、导入和学习里的加载 / 完成 / 失败
- **页** `--motion-page: 240ms`：本刀不新用
- **进入 / 位移** `--motion-ease-enter: cubic-bezier(0.22, 1, 0.36, 1)`
- **离开** `--motion-ease-leave: cubic-bezier(0.4, 0, 1, 1)`，略快

只动 `opacity` 和 `transform`。听写框在核对后的高度变化是即时的，不做宽高补间。`prefers-reduced-motion: reduce` 同时关掉 `transition` 和 `animation`；切句的 Web Animations 也在同一判断下跳过。

## 本刀做了什么

- 核对结果从输入区下方就近出现，按 Esc 或「修改」时按原路收回。对错仍用现有词色，没有抖动或逐字母着色。
- 切句只交代听写区本身，从略低的透明度淡入，不把整页卸掉，也不走到全透明，避免闪白。听写顶栏和播放器位置保持不动。连续切句会取消上一段动画再接到新句。
- 「显示画面 / 收起画面」用同一套短时长出现与收起，进行中再次点击接到新状态，不排队。画面展开时限制高度，并把主操作钉在听写区底部，避免在 1024×640 或更窄的窗口里把播放器和「修改 / 下一句」挤出窗外。隐藏时仍只改可见性，不卸载 `<video>`。
- 导入页的状态句、处理进度、失败说明，以及页内确认，和核对结果走同一套短节奏。
- 播放 / 暂停图标切换有轻微的微反馈；循环按下态保持可辨，但不另做装饰。
- 听读词高亮仍是 `transition: none`，跟随滚动继续走 `motionScrollBehavior()`。

## 不做

逐字母着色、连对动画、错词本；回头改库页提示挡住「最近学」、快捷键说明折行；改动 v0.1.3 Release。
