# UX-1 · 导入代劳

相对 `main@23d9b74`（v0.1.3）。本刀只改「选完文件到可以开始听写」这条主路径，不重做识别引擎，不覆盖 v0.1.3 Release，也不做 MOT-1 / UX-2 / UX-3 / MOT-2。

## 本刀做了什么

- 点「导入素材」后，空页只按「选择或拖入文件」理解；不再把「未命名素材」当作用户要处理的完成态，空投放区也不再挂识别设置、缓存管理等用不上的项。
- 桌面版导入还没有参考原文的音频后，自动开始准备字幕，进度为人话「正在准备字幕…」，可以取消；不要求先打开识别设置。
- 拖入或选中视频后沿同一条路做完：缺本地工具时先用人话征求同意并显示安装进度，默认用全程，有文本字幕轨就先自动选用，没有则自动识别。多音轨等例外才展开选择。OCR / 画面识别只作为自动路径失败后的退路，不是主路径上的默认勾选。
- 成功状态为「已准备好 n 句，可以开始听写」。校对放在「更多」里，不再把校对写成开始听写的前提。「开始听写」仍要求已经有参考原文。
- 默认识别失败时，才出现可理解的失败说明（第一句为人话，技术原因在「详情」）和「识别设置」。

## 不做

重做识别引擎；改变「下载本地工具需要一次明确同意」；覆盖 v0.1.3 Release；动效语言、听写壳去噪、通知/撤销、学习态变化。
