# V3 原型界面对照补齐

本轮以用户提供的 `attune-agent-handoff-ux-v1 (2).zip` 内实施规范、V3 HTML 与截图为依据。保留真实识别、数据迁移、字幕记录保护、共享播放和保存流程；没有复制原型中的模拟识别或翻译生成能力。

## 对照结果

| 页面 / 组件  | 本轮补齐                                                                             |
| ------------ | ------------------------------------------------------------------------------------ |
| 全局控件     | 白色与绿色原型色系，统一次级按钮、表单、焦点、禁用态；减少动态效果时关闭过渡         |
| 首页         | 页面标题与继续学习分层，紧凑继续卡和最近学习行图标；继续按钮显示真实视图名称         |
| 素材库       | 紧凑列表、文件夹分隔面板、素材图标与排序图标，统一搜索框                             |
| 新建素材     | 无音频时显示两个独立导入区；导入音频后进入就绪摘要，无字幕时只能开始听读             |
| 已有素材准备 | 音频、字幕、译文状态行；就地重命名、直接校对字幕、可展开识别设置；听写为主要开始操作 |
| 学习页       | 通栏播放器与素材标题、固定视图栏、居中听写区、逐词下划线、核对按钮与快捷键提示       |
| 听读 / 校对  | 沿用共享控件与局部滚动，统一间距、正文与状态层级                                     |

原型中翻译“生成”的演示不作为正式功能展示；缺少译文时提示导入双语字幕。键盘切句采用规范覆盖后的左右箭头。

## 验证

- 89 项单元测试通过。
- 浏览器回归 50 项通过，1 项可选 Logo 取色工具跳过。
- 生产构建、格式检查与 diff 空白检查通过。
- 1280×720 和 1024×640 核心控件可见性回归通过。
- 更新 `screenshots/` 页面图；子 agent 对首页、素材库、听写、1024×640 核对态和素材准备做了图片复查，未发现明确控件溢出。
- Windows release 程序重建通过（`tauri build --no-bundle`）；实际 WebView2 smoke 通过，覆盖 IPC、WAV/SRT 导入、播放、核对、完整原文和重启后的持久化。原生截图在 `test-results/native-smoke/dictation.png`。本轮没有重新生成安装器。

截图是使用测试素材得到的浏览器证据，不代表用户数据，也不代表实体输入法、系统文件选择器或扬声器听感验收。
