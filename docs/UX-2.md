# UX-2 · 听写壳去噪

相对 `main@8d21a88`（显示叠盖修正已合入）。本刀只去掉听写壳、首页和库页上的重复与空状态噪音，不重做信息结构，也不改通知形态（UX-3）或核对动效（MOT-2）。动效仍用 MOT-1 的时长和曲线。

## 改了什么

- **语速只留一种控件。** `···` 菜单里去掉「语速 · 1×」循环按钮，只留下拉。当前倍速写在标签上，例如「语速 · 1×」。语速能力还在。
- **「重听本句」改为图标。** focus 播放器上用 ↺ 图标，并带无障碍名称「重听本句」。单句循环仍是 ↻ 开关。核对区保留「↻ 重听」。循环是开关，重听是立刻再播这句。
- **句序只留一处。** 听写里用状态行的「01 / 02」打开句子列表，不再在标题里写一遍「第 n / m 句」。
- **首页空状态。** 没有更多最近学习时，不再显示「暂无更多最近学习」。只有一条「上次学习」时也不会出现这行。
- **库页文件夹下拉。** 还没有自建文件夹时，主工具行不放文件夹下拉；可以用「＋ 文件夹」新建。建了文件夹之后，筛选下拉会出现。

#21 已修好的显示问题保持：菜单不得切掉「核对答案」；离开菜单不留下半透明叠字；快捷键横幅仍在预留带里，不挡句序、不与顶栏相交。

## 不做

通知改成 toast、关闭 / 自动消失、删除撤销、系统 confirm（UX-3）；核对结果出现 / 收回、切句闪白、画面显隐（MOT-2）；另写一套动效曲线；改 UX-1 软口；动 main 或 v0.1.3 Release。
