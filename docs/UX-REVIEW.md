# Attune UX 交接核对

核对日期：2026-10-12 至 2026-10-13。基线为 `main@7962aaf`，交接分支包含 `6b84c95`、`7b507d1`、`2b4f5fe`。依据交接包中的 V1 实施规范检查实际代码与运行结果；交接截图中的完成声明没有作为验收证据。

原实现已经具备首页、素材库、迁移、素材准备、字幕编辑、听写、听读与轮次的主要结构，但不能认定全部完成。本次补齐了以下问题。

| 问题                                                                       | 修复结果                                                                             |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 播放/暂停标记始终为 false，timeupdate 反复设置 currentTime，循环可能被覆盖 | 使用真实媒体事件更新状态；跨过句末也能停止，循环回到选定句开头                       |
| 二级页面重建播放器与学习状态                                               | 同一素材的页面共享一个音频实例；保留编辑句、草稿、核对态、视图、语速、循环与阅读设置 |
| StrictMode 初始化清理可能把恢复位置覆盖成零                                | 音频元数据加载后才保存位置；增加重新打开素材恢复到第 4 秒的回归测试                  |
| 完整原文点击只改数据库时间，没有播放                                       | 定位并启动共享播放器，不改变原来的听写编辑句                                         |
| 替换音频仅改内存，数据库缓存只按 ID 判断                                   | 按 Blob 身份更新音频存储，事务成功后才更新缓存；普通草稿保存不复制音频               |
| 新建按钮不进入准备流程，两个开始按钮行为相同                               | 新建直接进入素材准备；分别开始听写/听读，并返回实际来源页                            |
| 本地识别只有设置，没有执行入口                                             | 增加开始识别、首次下载确认；阻止重复启动，退出准备页取消任务                         |
| 已完成句重新核对后仍显示待重新核对                                         | 清除对应 stale 标记，避免重复累计完成句                                              |
| 拆分生成空句，未提供文字光标位置                                           | 指定文字光标与时间；保留原句草稿，受影响记录标记待重新核对                           |
| 合并丢弃后句草稿、译文、难句，完成 ID 未清理                               | 确认后连接两句草稿和译文、迁移难句、清理消失的完成 ID；保留旧兼容档案                |
| 删除素材可能被待写入的自动保存重新创建                                     | 删除进入保存队列，清除待保存条目，失败时报告错误                                     |
| Esc 没有解除输入焦点；组合键可能被学习导航拦截                             | 恢复原生编辑作用域、IME 阻断与非输入导航                                             |
| 镜像层归一化空格造成光标与文本坐标错位                                     | 镜像保持原始字符串并同步滚动，核对算法单独忽略常规标点                               |
| 听读的程序滚动也抑制自动跟随，中文模式无译文时空白                         | 只在用户滚动时临时抑制，提供回到当前句；无译文退化到英文                             |
| 小窗口核对区与页脚重叠，长列表依赖整页滚动                                 | 播放器和操作行固定，内容区内部滚动；增加两种窗口尺寸的可见性断言                     |
| ICO 的图像目录偏移错误，Windows RC 编译失败                                | 修正累计偏移，重新生成所有 PNG/ICO，完成原生编译与 NSIS 打包                         |

## 本地验证

- `npm test`：89 个单元测试通过，包含 v1/v2/空库迁移、字幕记录保护与替换音频持久化。
- `npm run test:e2e`：48 个检查通过。另有一个只用于概念板取色的可选工具，需要 `ATTUNE_LOGO_REFERENCE`，默认跳过。
- `npm run test:rust`：14 个常规测试通过；三个真实外部环境测试默认 ignored，不能计入常规通过数量。
- `npm run build`、`npm run format:check`、`git diff --check` 通过。
- `npm run tauri build`：Windows x64 可执行程序及 NSIS 安装包构建成功。
- `npm run test:native`：实际运行打包后的 WebView2 应用，验证 Tauri IPC、WAV/SRT 导入、真实播放与句末停止、核对、原文播放、草稿和核对态重启恢复。使用随机本机调试端口和独立 WebView2 数据目录，测试前确认数据库为空。
- 1280×720 与 1024×640：检查播放器、输入和页脚均在窗口内；页面不滚动，长内容在内部滚动。

浏览器图片位于 `screenshots/`；`native-webview2.png` 来自实际 Windows WebView2。产品截图中的示例素材属于测试数据，不随生产应用创建。

## 保留的边界

- 文件导入测试通过自动化指定文件路径，未模拟人在系统文件对话框内的选择过程；SRT 保存对话框仍需人工验证。
- IME 自动化只验证组合事件不会触发核对/切句；实体中文输入法、真实选区/撤销体验与扬声器听音仍需人工验收。
- 实体安装器安装/卸载未执行；已验证安装包生成与内含程序启动。
- 字幕拆分后原有中文保留在前半句，需要按实际内容人工校对；不自动编造拆分翻译。
- 真实模型下载与识别验收结果另见下方记录；不能用普通 Rust 单元测试冒充识别端到端验证。

## 模型网络验收记录

首次真实续传测试使用了 `test-results`，该目录同时被 Playwright 清理，因此该次验证没有可靠的环境隔离；最终文件校验被拒绝，未启用模型，失败根因没有完整确认。该下载测试不计为通过。

随后改用 `node_modules/.cache/native-asr` 独立缓存，下载完整的 `ggml-tiny.en.bin`。实际文件长度为 77,704,715 字节，SHA-256 为 `921e4cf8686fdd993dcd081a5da5b6c365bfde1162e72b08d75ac75289920b1f`，与代码中的模型目录一致。

使用 Microsoft Zira 合成的 10.7 秒英文 WAV 执行真实 whisper 集成测试：`real_transcription_of_a_clip` 与 `real_transcription_can_be_cancelled` 均通过，合计约 1.1 秒；识别得到四句英文及词时间戳。模型只放在测试缓存中，没有安装进用户应用数据目录。本次覆盖真实 Rust 识别与取消，不等于在原生界面完整操作模型下载和识别流程。

## 复现命令

```powershell
rtk npm test
rtk npm run test:e2e
rtk npm run test:rust
rtk npm run format:check
rtk npm run tauri build
rtk npm run test:native
```

已准备模型和 WAV 的当前工作区可复现真实识别测试：

```powershell
$env:ATTUNE_TEST_MODEL="D:\code\Attune\node_modules\.cache\native-asr\models\ggml-tiny.en.bin"
$env:ATTUNE_TEST_WAV="D:\code\Attune\node_modules\.cache\native-asr\english.wav"
rtk npm run test:rust -- -- --ignored real_transcription --nocapture
```

真实模型/识别测试请使用独立缓存目录，不放入会由 Playwright 清理的 `test-results`。
