# UI S3 · 专注听写·听读

相对 S2（main@a8bdd07）与已发布的 [v0.1.2](https://github.com/Nicander93/Attune/releases/tag/v0.1.2)，本刀只改学习页专注壳与听写/听读交互，不重做导入或首页/库 IA。

设计基线：克制版交互原型 V2（专注学习屏）。

## 本刀做了什么

- 进入听写/听读后隐藏壳层「首页 / 素材库」全局导航；返回仍走来源页。
- 专注顶栏：返回、素材名、听写↔听读同壳切换、···（句子列表 / 难句过滤 / 按键音 / 轮次 / 校对字幕 / 完整原文 / 素材设置 / 快捷键）。
- 句号计数可展开句子列表；难句星标；播放器保留切句 / 播放 / 循环 / 语速 / 按句·连续。
- 听写核对后视频素材可「显示画面」；切换显隐不重挂时钟（沿用 P2 MediaOutput）。
- 键盘：Enter 核对/下一句、Space 播放、←→ 切句（输入框外）、Esc 从核对回改 / 关菜单 — 不回归。

## 刻意未改

- S1 首页 / 素材库壳、S2 导入收敛主路径。
- 视频 / OCR / 缓存 / ffmpeg 能力（仍从素材设置 / 导入更多进入）。

## 不做

社交 / 账号、云同步、重做识别引擎、并入 my-web-gis、为美观删掉已上线的视频 / OCR / 缓存能力。
