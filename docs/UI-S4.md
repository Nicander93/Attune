# UI S4 · 壳视觉

相对 S3 合入后的 `main@8a4964f`（S1–S3 信息架构已齐），本刀只做**壳层视觉与文案层级**，不碰专注听写去噪（S5）、也不切 v0.1.3 安装包。

设计基线：克制版交互原型 V2（纸感色板、四条绿柱品牌、首页恢复卡、库工具行、导入空态）。

## 本刀做了什么

- 色板 / 字号 / 间距贴近 V2 纸感（`--bg #fbfbf9`、`--accent #315843` 等）；顶栏高度与导航间距对齐原型。
- 品牌标记改为四条绿柱；主导航 active 用文字加粗，去掉灰绿胶囊底。
- 首页「上次学习」恢复卡：去掉旧卡片边框阴影冲突；标题 + 副标 |「继续」同一行，细进度条贴在下方。
- 素材库工具行只留搜索 / 文件夹 / 排序；「当前文件夹 · N 段」与「＋ 文件夹」及文件夹重命名/删除下沉到次级 meta 行。
- 导入空态：上传图标 +「音频或视频」一体；提示改为「或拖入文件」，不再把视频能力文案赶到「更多」；拖入/选择视频与「更多 → 导入视频」仍可达。

## 刻意留给 S5

- 专注听写屏控件收进顶栏 / `···`、听写↔听读单按钮、默认藏画面核对后再显、去掉常驻底栏与播放器旁勾选群。

## 不做

社交 / 账号、云同步、重做识别引擎、并入 my-web-gis、为美观删掉已上线的视频 / OCR / 缓存能力、`attune-proto-v2/design.md` 逐字母 / 错词本、v0.1.3 安装包。
