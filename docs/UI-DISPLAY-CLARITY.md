# 显示叠盖修正

相对 `main@d272968`（MOT-1 已合入）。本刀只收产品收回 PASS 后指出的三处文字 / 界面叠盖，不开 UX-2，也不把通知改成 toast（UX-3）。

## 怎么改的

1. **动效进行中不要两层字叠在一起。** 菜单、句子列表这类浮层离开时立刻卸掉，不再淡出半透明文字。进入时第一帧就是实底（只轻微位移/缩放），避免半透明菜单字盖在「核对答案」或其他标签上。从菜单里点「快捷键」会马上关掉菜单再出横幅。

2. **菜单完全打开时不要切掉「核对答案」。** 听写菜单加了最大高度和内部滚动，打开时按「核对答案」（或核对后的操作行）的上沿计算可用高度，菜单底边停在主按钮上方。菜单用实底 `#fff`，背景字不会透过来。语速的两个控件（「语速 · 1×」按钮和「语速」下拉）原样保留，留给 UX-2 再收。

3. **快捷键说明不要挡住句序，也不要和顶栏相交。** 横幅仍是横幅，关闭和自动消失策略未改。顶栏高度以实测盒模为准：页面上用 `--banner-top` 对齐当前可见顶栏（学习态是学习顶栏，离开后是全局顶栏）的底边，不再写死 54px。全局顶栏的样式高度统一为 `--shell-topbar-height: 66px`（这是 S4 的实际高度；先前横幅按 54px 对齐才会和顶栏相交约 12px）。

   听写里，顶栏正下方没有足够空白同时放下横幅又露出「01 / 02」那一行，所以给横幅预留一条带，把句序行往下推一点。这样学习顶栏、「01 / 02」/星标/「已听写」都露在外面，横幅叠在顶栏和句序之间的预留带上。离开听写后，横幅落在全局顶栏下方，导入页因此也给横幅留出一条带，避免和顶栏或标题相交。

## 不做

语速双控件的合并或删减（UX-2）；通知改成 toast 或改关闭策略（UX-3）；听写核对动效（MOT-2）；改 UX-1 软口；动 main 或 v0.1.3 Release。
