# UI S5 · 专注去噪

相对 S4 合入后的 `main@cb66bda`（含 #16 证据），本刀只改**专注听写·听读壳**的控件层级，不重做 S4 壳视觉，也不切 v0.1.3 安装包。

设计基线：克制版交互原型 V2（专注学习屏）。

## 本刀做了什么

- 顶栏收敛为：返回 / 文件名 / 单按钮「听读↔听写」/ `···`。
- 语速、按句·连续、句子列表、难句过滤、自动跟随、未听写原文、轮次、校对字幕、完整原文、素材设置、快捷键、按键音全部进 `···`（或保留隐藏 a11y 控件）。
- 播放器旁去掉常驻语速下拉与勾选群；单句循环改为图标按钮（`aria-pressed`）。
- 去掉常驻底栏快捷键条与「只看难句 / 轮次」工具行。
- 听读主路径只留英文 / 双语轻切换；自动跟随与「显示未听写的原文」下沉到菜单（仍可用隐藏 checkbox 驱动）。
- 听写与听读默认藏视频画面；核对后提供「显示画面」；不重挂 P2 `MediaOutput` 时钟。
- 键盘 Enter / Space / ←→ / Esc 行为保持。

## 刻意未改

- S1 首页 / 素材库壳、S2 导入主路径、S4 纸感色板与品牌。
- 视频 / OCR / 缓存 / ffmpeg 能力（仍从更多 / 素材设置进入）。
- `attune-proto-v2/design.md` 逐字母 / 错词本。

## 不做

社交 / 账号、云同步、重做识别引擎、并入 my-web-gis、为美观删掉已上线的视频 / OCR / 缓存能力、v0.1.3 安装包。
