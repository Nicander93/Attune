# UX-3 · 通知、确认、撤销

相对 `main@98e55cd`（UX-2 已合入）。本刀把成功和说明改成不占版心的短时提示，删除后可以在短时间内撤销，并把已经看见的三处空和挤一并收掉。不改核对动效（MOT-2），也不改 v0.1.3 Release。动效仍用 MOT-1 的时长和曲线。

## 改了什么

- **成功和说明改为 toast。** 提示浮在标题行下方右侧，不挡住首页和库页的「导入素材」按钮，也不再用顶部横幅把主栏或听写区顶下去。信息类提示会在几秒后自动消失，也可以点关闭或按 Esc 关掉。出错提示会留下来，直到用户关掉或问题解决；保存失败时仍可「重试保存」。
- **「快捷键」在菜单里说明。** 点「快捷键」会在菜单里展开一份简短说明，不再弹出横幅，也不会把输入区和播放器顶走，更不会挡住「核对答案」、句序或顶栏。
- **删除素材和文件夹可以撤销。** 仍放在行菜单里，不再弹出系统确认框。删除后条目先从列表里消失，并出现带「撤销」的提示；短时间内可以恢复。真正从本机清掉要等到这段时间结束，或用户关掉提示并等到窗口到期。删除文件夹只会把其中素材移到未分类。
- **清理缓存和安装本地工具改为页内说明。** 用一段人话说明后果，用户点一次同意后再继续。安装进度仍写在页面里。主路径文案不堆工具名、许可缩写和目录路径；失败时第一句仍是人话，技术原因放在「详情」。
- **一并收掉的三处空和挤：** 首页只有一条上次学习时，不再出现空的「最近学习」标题和「全部素材」入口；菜单里语速标签只写「语速」，倍速只出现在下拉里；循环和重听改用外形不同的图标（循环是带「1」的闭环，重听是带回退竖线的箭头）。核对区仍保留「重听」文案。

#21 和 UX-2 已修好的显示与去噪保持：菜单不得切掉「核对答案」；动效中不得两层字叠在一起；语速只留一种控件；播放条上不回到「重听本句」长文案；句序只留一处。

## 不做

核对结果出现 / 收回、切句闪白、画面显隐（MOT-2）；把整个界面推倒重做；另开一刀专门收空和挤；改 UX-1 软口「待校对」；动 main 或 v0.1.3 Release。
