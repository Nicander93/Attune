### 几何与人眼补充

- **导入提示：** toast 主机是 `position: fixed`，落在顶栏和标题行之下、右侧，文案「音频已导入：speech.wav」。与输入区、播放器、「核对答案」、句序、标题均无相交。因全局提示改位，本张已重拍。
- **快捷键说明：** 说明块在可滚动的听写菜单里。打开后菜单最小宽度加到 228px，便于把「核对或进入下一句」一类短句放下。较长的「在输入框外」仍会在句末折行，但整段看得见。菜单会盖住输入框右侧一角，这和打开菜单时本来就会盖住右侧的情况一样；输入区和播放器没有被顶走，「核对答案」、句序、顶栏均无相交。
- **删除：** 删除时 `window.confirm` 调用次数为 0；当前文件夹条数 68 → 67；提示含「撤销」。提示盒子为 `(644,144)–(1004,197)`，「＋ 导入素材」为 `(860,80)–(962,118)`，二者无相交；按钮中心命中测试落在按钮上，而不是提示上。点撤销后条数回到 68，被删的「h264_aac_subs」回到列表顶部。因提示改位，本张已重拍。
- **安装本地工具：** 页内说明写清体积（约 79 MB）和「只用于本机」，按钮为「同意安装」「取消」，在 1024×640 下整段和两颗按钮都看得见，没有被裁切。
