# UI S2 · 导入收敛

相对 S1（`main@9c490eb`）与已发布的 [v0.1.2](https://github.com/Nicander93/Attune/releases/tag/v0.1.2)，本刀只收敛导入页信息架构，不碰专注听写壳。

设计基线：克制版交互原型 V2（导入屏）。

## 本刀做了什么

- 导入主路径：空态单一拖放区（音频或视频提示）→ 选择/拖入 → 就绪态文件行 + 状态文案。
- 主 CTA：「校对字幕」（待校对时）与「开始听写 →」；不再并列多块「素材准备」分区。
- 「更多 ···」收纳：导入字幕文件、识别设置、导入视频（含音轨 / OCR / 按需 ffmpeg）、缓存管理、重命名、开始听读。
- 视频导入与 `VideoImportPanel`（探测、抽轨、OCR、ffmpeg 下载/重建）仍可达，未删除能力。
- 首页 / 素材库 S1 壳保持可用；旧素材仍可从库进入导入页。

## 刻意留给 S3

- 专注模式学习壳（无全局导航）。
- 听写 / 听读同壳切换、句号 / 难句 / 循环 / 语速 / 快捷键进顶部或 `···`。
- 视频默认藏、核对后「显示画面」等专注交互规则。

## 不做

社交 / 账号、云同步、重做识别引擎、并入 my-web-gis、为美观删掉已上线的视频 / OCR / 缓存能力。
