# UI S1 · 壳层首页与素材库

相对已发布的 [v0.1.2](https://github.com/Nicander93/Attune/releases/tag/v0.1.2)，本刀只改信息架构与壳层，不碰导入收敛或专注听写。

设计基线：克制版交互原型 V2（首页 / 素材库）。

## 本刀做了什么

- 壳层主导航仍为「首页 / 素材库」；品牌回首页。
- 首页标题改为「继续学习」；主 CTA「＋ 导入素材」。
- 「上次学习」恢复卡：标题、听写 · n / m 句、进度条、「继续 →」。
- 「最近学习」列表不再重复恢复卡那一项；「全部素材 →」跳素材库。
- 素材库工具行：搜索 + 文件夹下拉 + 排序（最近学习 / 名称 / 时长）。
- 素材行：音/视频标记、名称、分类 · 时长；状态优先显示「待校对」；行内 `···` 保留重命名 / 移动 / 删除 / 素材准备。
- 旧素材仍可打开；视频 / OCR / 缓存 / ffmpeg 能力未删除，仍从素材准备进入。

## 刻意留给 S2 / S3

- S2：导入路径收敛（拖入 → 就绪 → 听写；高级项进「更多」）。
- S3：专注模式学习壳（无全局导航）、听写 / 听读交互与键盘专注规则。

## 不做

社交 / 账号、云同步、重做识别引擎、并入 my-web-gis、为美观删掉已上线的视频 / OCR / 缓存能力。
