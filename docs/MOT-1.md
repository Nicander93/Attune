# MOT-1 · 动效语言（壳层出现 / 消失）

相对 `main@0e99b70`（UX-1 已合入）。本刀只把共用动效 token 落到样式，并先交代壳层的出现与消失。不改听写核对的内容逻辑（MOT-2），也不把通知改成 toast（UX-3）。

## Token

定义在 `src/app/styles.css` 的 `:root`，毫秒值与 `src/app/motion.ts` 的 `MOTION_MS` 保持一致：

- **微** `--motion-micro: 100ms`：按下、悬停、投放区拖入、图标一类的轻反馈
- **短** `--motion-short: 180ms`：菜单、通知、控件显隐、顶栏离开
- **页** `--motion-page: 240ms`：页面进入、顶栏进入；不超过 280ms
- **进入 / 位移** `--motion-ease-enter: cubic-bezier(0.22, 1, 0.36, 1)`
- **离开** `--motion-ease-leave: cubic-bezier(0.4, 0, 1, 1)`，略快；项目里不再另写一套贝塞尔

只动 `opacity` 和 `transform`。进度条、音量、时间轴明确写了 `transition: none`，拖动时跟手。宽高不做补间。

`prefers-reduced-motion: reduce` 同时关掉 `transition` 和 `animation`，并把 `scroll-behavior` 设回即时。听读跟随滚动也走同一判断（`motionScrollBehavior()`），不会在媒体查询之外另开一条动画。

## 本刀做了什么

- 首页 / 库 / 导入等页面切换：新页以「页」时长从下轻移并淡入。工作区（含播放器）不拆开重挂，避免为离场再叠一层而打乱播放状态。
- 进入听写时顶栏上移淡出，离开时按原路回来；听写中顶栏仍挂在 DOM 里但不可用、离开后不可见，避免中途操作点到已退出的导航。
- `···` 菜单和句子列表从按钮附近出现与收起，进行中再次开关接到新状态，不排队。
- 投放区拖入时有轻微缩放；按钮在现有颜色变化上加了不抢戏的按下缩放，都用「微」。
- 通知仍是横幅，但改为叠在内容之上出现 / 消失，不再把页面顶开。可打断。更理想的形态留给 UX-3。

## 滚动手感怎么量的

开发机（Windows LM）上查看了样式与结构，并在有多条素材的库、以及听读长文视图里用手滚动：

- 素材库列表和听读正文都在各自的 `overflow: auto` 容器里滚，页面壳本身不滚。
- 列表没有一项项错落入场，数字没有跳动计数。
- 听读词高亮仍是 `transition: none`，跟随滚动在系统「减少动态效果」下改为即时对齐。

本刀没有做逐帧性能剖析。若真机长列表出现掉帧，再另记，不在本片扩大范围。

## 不做

听写核对结果的出现与收回、切句内容交代、显示 / 收起画面（MOT-2）；通知改为 toast（UX-3）；暗色主题；改 UX-1 软口。
